# VIBGARD
VibeGuard, KOBİ'ler için düşük maliyetli, yapay zekâ destekli bir kestirimci bakım sistemidir. Bir akıllı telefon veya birkaç dolarlık bir MEMS ivmeölçer makineye takılır, sistem makinenin sağlıklı titreşim imzasını yaklaşık 20 saniyede öğrenir ve sonrasında arızaları canlı olarak tespit eder.
